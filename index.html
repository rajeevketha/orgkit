OrgKit

Daily Salesforce work in the org already open in Chrome — Query, Schema, Compare, Apex. Uses your tab session in the browser only. No extra login.

What you use every day

  • Query — plain English or SOQL against this org
  • Schema — how record types connect, plus field describe
  • Compare — UAT vs Prod, or any two flow versions
  • Apex — anonymous Apex and debug output
Chrome Web Store Privacy policy Support

Already installed?

  • If you installed OrgKit from the Chrome Web Store, Chrome updates it on this computer. You do not install a second copy.
  • After the Store publishes a new version, Chrome usually applies it within a few hours. You can also open chrome://extensions and click Update.
  • If you loaded an unpacked zip for testing, that copy does not auto-update. Remove it after you install from the Store, so you only have one OrgKit.

Privacy

  • No OrgKit backend collecting your org data
  • Uses the Salesforce session already open in Chrome
  • Never stores sid
