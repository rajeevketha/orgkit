# OrgKit — downloadable packages

## Current (1.8.2 — Session Workbench + multi-category Org Compare)

- `OrgKit-1.8.2-unpacked.zip` — unzip → Chrome Load unpacked (local testing)
- `OrgKit-1.8.2-store.zip` — same payload (manifest at zip root)
- `OrgKit-CURRENT.zip` / `OrgKit-store.zip` — stable aliases

### Test locally

1. Download and unzip `OrgKit-1.8.2-unpacked.zip`
2. Chrome → `chrome://extensions` → Developer mode
3. **Load unpacked** → select the unzipped folder
4. Open logged-in Salesforce tabs (any Chrome windows) → Alt+Shift+O
5. Org Compare → pick sessions with Set as A/B → choose categories → Compare
