# OrgKit — downloadable packages

## Current (1.8.1 — Session Workbench + Org Compare)

- `OrgKit-1.8.1-unpacked.zip` — unzip → Chrome Load unpacked (local testing)
- `OrgKit-1.8.1-store.zip` — same payload (manifest at zip root)
- `OrgKit-CURRENT.zip` / `OrgKit-store.zip` — stable aliases

### Test locally

1. Download and unzip `OrgKit-1.8.1-unpacked.zip`
2. Chrome → `chrome://extensions` → Developer mode
3. **Load unpacked** → select the unzipped folder
4. Open logged-in Salesforce tabs for the orgs you want to compare → Alt+Shift+O
5. Home = Session Workbench; open **Org Compare** from quick launch or All tools
