DETAILED DESCRIPTION
================================================================================

OrgKit is for the Salesforce work you already do in Chrome.

You stay in the org you logged into. OrgKit uses that tab session — it does not ask for a password and does not store your session id.

Daily tools
• Query — describe the rows in plain English, or run SOQL / Tooling
• Schema — a map of how record types connect, plus a field describe
• Compare — UAT vs Prod (objects, permissions, live flow versions) or any two flow versions in the same org or across two orgs
• Apex — anonymous Apex and debug output
• Home — continue recent work, pinned queries, a per-org scratch pad

Also available under More: inactive flow versions, package.xml, permissions, metadata jump, record Ids, and heuristic scans for pasted logs/errors/Apex.

How authentication works
OrgKit does not ask you to type a password into the extension. It uses the Salesforce session cookie from a Salesforce tab you already logged into in Chrome, only to call Salesforce APIs for actions you start. The session stays in your browser. This is the same session model used by tools such as Salesforce Inspector Reloaded.

Org Compare picks orgs from open Salesforce tabs across Chrome windows (same profile) and optional cookie sessions. It never stores sid.

Privacy & permissions
• No OrgKit backend collecting org data
• Session id is not written to sync storage and is not sent to AI providers
• Optional AI sends only the text you paste, to the endpoint you configure
• Full policy: https://rajeevketha.github.io/orgkit/privacy.html

Permissions (summary)
• cookies — Salesforce sid on Salesforce domains only
• storage — settings, favorites, saved SOQL, workbench history/scratch, last Org Compare A/B org keys (never stores sid)
• tabs — list open Salesforce tabs across windows for Active session / Org Compare
• Host permissions — Salesforce domains only; OpenAI hosts are optional
• Does not request activeTab or scripting

================================================================================
SINGLE PURPOSE
================================================================================

OrgKit lets Salesforce developers do daily work in the org already open in Chrome: query data, read schema, compare two orgs or flow versions, and run anonymous Apex — using the browser Salesforce session from a logged-in tab.
